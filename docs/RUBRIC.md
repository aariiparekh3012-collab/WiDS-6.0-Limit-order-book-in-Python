# Project completion criteria

| Stage | Evidence of completion |
|---|---|
| Foundation | Correct limit and market matching, cancellation, top and depth; 3/3 traces and design notes |
| Advanced | IOC, FOK and passive modification; 7/7 cumulative mandatory traces and five independent tests |
| Performance | Repeatable measurements and interpretation; Intermediate track adds profiling and an optimisation attempt |
| Quantitative research | Reproducible notebook, feature engineering, baseline comparison, logistic regression, chronological validation and limitations |
| Final submission | Individual repository with clear instructions, source, tests and concise project report or detailed README |

Both benchmark tracks are equally valid. Cancel Newest is an optional extension. A well-explained negative or null result is acceptable. Assessment focuses on correctness, independent work, sound methodology and reproducibility rather than raw speed or predictive accuracy.
